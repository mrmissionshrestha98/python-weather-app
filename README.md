A desktop weather application built with Python, PyQt5, and the OpenWeather API. Displays temperature, weather conditions, and weather emojis for a user-entered city.

# Python Temperature Converter 🌡️

## About the Project

This is one of my first Python practice projects, developed while I was learning Python by following a tutorial from Bro Code on YouTube. 

The program converts temperatures between Celsius and Fahrenheit based on the user's input. It helped me practice basic Python programming concepts and understand how conditional statements and user input work.

## Features

- Convert Celsius to Fahrenheit.
- Convert Fahrenheit to Celsius.
- Accept user input for the temperature and unit.
- Display the converted temperature rounded to one decimal place.
- Handle unsupported unit inputs.

## Python Concepts Practiced

- Variables and data types
- User input and type conversion
- `if`, `elif`, and `else` statements
- Arithmetic operations
- `round()` and formatted output

## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Run the following command:

   ```bash
   python temperature_converter.py
   ```
